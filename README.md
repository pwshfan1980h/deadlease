# FREEBORN

[Play FREEBORN](https://pwshfan1980h.github.io/deadlease/) — a keyboard-driven roguelike in the Marrow Estuary. Transcript-led interface with a room thumbnail beside player data and a large artwork preview on hover or focus.

This **main** branch contains the tested GitHub Pages build. Editable code, assets, tests and project documentation are on the [source branch](https://github.com/pwshfan1980h/deadlease/tree/source).

Current additions: lasting conditions and paid doctor treatment, ranked implants bought with credits or earned through the Spare Parts commission, plus red HP/yellow stamina gauges and a taller transcript. Previous additions: permadeath and fresh clinic intake, packed Stitch Drone revival, marksman aim/reload, bleeding knife fighters, overheated tread brutes and human surrender. Earlier work includes fishing, timing interactions and personal missions.

## Scene and terminal playtest

All 149 rooms have unique paintings. Room inhabitants and grey loose-item lists appear immediately; type `look around` for deeper detail. Item mentions in prose are bright green, neutral names blue, hostile names red. The transcript is green on black. Inhabitants, loose items and illustrated encounters live inside the transcript. Clickable actions and typed commands both work; hidden opportunities still need observation.
