# FREEBORN

[Play FREEBORN](https://pwshfan1980h.github.io/deadlease/) — a keyboard-driven roguelike in the Marrow Estuary. Scene-first stacked interface with a centered desktop frame, responsive to standard and wide monitors.

This **main** branch contains the tested GitHub Pages build. Editable code, assets, tests and project documentation are on the [source branch](https://github.com/pwshfan1980h/deadlease/tree/source).

Current additions: permadeath and fresh clinic intake, packed Stitch Drone revival, marksman aim/reload, bleeding knife fighters, overheated tread brutes and human surrender. Earlier work includes fishing, timing interactions and personal missions.

## Scene and terminal playtest

All 149 rooms have unique paintings. Room inhabitants and grey loose-item lists appear immediately; type `look around` for deeper detail. Item mentions in prose are bright green, neutral names blue, hostile names red. The transcript is green on black. Typing remains primary; the mouse is visible for fallback use and inventory dragging.
